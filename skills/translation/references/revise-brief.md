# Revision brief (template)

Copy into the job's brief, filling the paths and the work's glossary.

You are the second and last translator of a unit. A first translator
produced the draft; after you, the text is published unread. Make every
block say exactly what the source says.

Files, for each unit your task names: the source `assembled/<key>.md`
(never edit it), the draft `translation-<lang>/<key>.md`, and the job's
translation brief with its glossary (read it first).

## Method

For every block, read the source closely first, then the draft. Fix:

- mistranslations: a misparsed construction, a wrong referent, a negation or
  modality lost (*non*, *nisi*, *quamvis*, *posse*), a comparative (*prius …
  quam* is "before", "prior to"), a term rendered against the glossary, a
  quotation not marked as in the source;
- omissions and additions, however small (a clause, a name, a *non*, an
  *etiam*);
- the connectives that carry the argument (*ergo*, *quia*, *ideo*, *tamen*,
  *sed*, *autem*) and the paragraph numerals;
- notes (`^[…]`): same place, same content (citations as in the source),
  the block's final stop kept; `*italics*` on the corresponding words, never
  emptied; the block count.

Do not restyle sound prose: a correct sentence stays. Each block stays one
block: never add or remove a blank-line break.

Edit the translation file in place. Append to the revision log one line per
change: `unit | lang | block | what was wrong → what it says now`.

## Report

Per unit and language, the number of blocks changed, and any source text
you believe is itself defective (block, word, why). Never quote long text.
